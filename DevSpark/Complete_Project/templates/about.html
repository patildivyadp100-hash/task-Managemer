About TaskFlow & REST API Reference

Architecture overview and comprehensive REST API endpoint documentation.

Project Architecture (Modules 18 — 26)

TaskFlow is a production-ready web application and REST API built with Flask, SQLite, and WTForms following clean software architecture principles:

📁 app.py

Application factory, central config loading, blueprint registration, and global error handlers.

📁 database.py

SQLite schema initialization, connection management via row factory, and complete CRUD SQL queries.

📁 models.py

Data conversion layer transforming SQLite rows into JSON dictionaries, plus domain status constants.

📁 forms.py

Flask-WTF forms providing CSRF protection and server-side validation rules.

📁 routes/

Modular Flask Blueprints separating Task views/APIs (task_routes.py) from User endpoints (user_routes.py).

📁 config.py

Production environment configuration managing SECRET_KEY, DATABASE path, and DEBUG mode.

REST API Endpoints

All endpoints accept and return JSON with standard HTTP status codes.

Content-Type: application/json
Method Endpoint Description Success Code
POST /api/users Create a new user (requires name and email). 201 Created
GET /api/users Retrieve all registered users. 200 OK
GET /api/users/<id> Retrieve single user by ID. Returns 404 if not found. 200 OK
GET /api/users/<id>/tasks List all tasks assigned to a specific user (User–Task relation). 200 OK
POST /api/tasks Create a new task. Requires title; optional description, status, user_id. 201 Created
GET /api/tasks Retrieve all tasks. Supports filtering via ?status=pending. 200 OK
GET /api/tasks/<id> Retrieve single task by ID. Returns 404 if not found. 200 OK
PUT /api/tasks/<id> Update task title, description, status, or assigned user. 200 OK
DELETE /api/tasks/<id> Permanently delete a task by ID. Returns 404 if not found. 200 OK

Quick Testing with cURL / PowerShell

1. Create a User (POST /api/users)
curl -X POST http://127.0.0.1:5000/api/users \
  -H "Content-Type: application/json" \
  -d '{"name": "Alice Smith", "email": "alice@example.com"}'
2. Create a Task (POST /api/tasks)
curl -X POST http://127.0.0.1:5000/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title": "Deploy to Render", "description": "Configure Gunicorn and live DB", "status": "in_progress", "user_id": 1}'
3. Filter Tasks by Status (GET /api/tasks?status=in_progress)
curl -X GET "http://127.0.0.1:5000/api/tasks?status=in_progress"
